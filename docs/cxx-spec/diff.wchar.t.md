# C.6.2.2 Type `wchar_t` [diff.wchar.t]

[Contents](README.md) · up: [C.6.2 Modifications to definitions \[diff.mods.to.definitions\]](diff.mods.to.definitions.md) · prev: [C.6.2.1 Types `char16_t` and `char32_t` \[diff.char16\]](diff.char16.md) · next: [C.6.2.3 Header `<assert.h>` \[diff.header.assert.h\]](diff.header.assert.h.md)

**1** The type `wchar_t` is a distinct type rather than a typedef to an existing integral type. The token `wchar_t` is a keyword in this International Standard ([[lex.key]](lex.key.md)). It does not appear as a macro or type name defined in any of `<cstddef>` ([[cstddef.syn]](lib/cstddef.syn.md)), `<cstdlib>` ([[cstdlib.syn]](lib/cstdlib.syn.md)), or `<cwchar>` ([[cwchar.syn]](lib/cwchar.syn.md)).
