# 25.1 General [algorithms.general]

[Contents](../README.md) · up: [25 Algorithms library \[algorithms\]](algorithms.md) · prev: [25 Algorithms library \[algorithms\]](algorithms.md) · next: [25.2 Algorithms requirements \[algorithms.requirements\]](algorithms.requirements.md)

**1** This Clause describes components that C++ programs may use to perform algorithmic operations on containers ([[containers]](containers.md)) and other sequences.

**2** The following subclauses describe components for non-modifying sequence operations, mutating sequence operations, sorting and related operations, and algorithms from the ISO C library, as summarized in [Table 91](algorithms.general.md#tab:algorithms.summary).
