# 23.5.3.2 Requirements [move.iter.requirements]

[Contents](../../README.md) · up: [23.5.3 Move iterators and sentinels \[move.iterators\]](move.iterators.md) · prev: [23.5.3.1 Class template `move_iterator` \[move.iterator\]](move.iterator.md) · next: [23.5.3.3 Construction and assignment \[move.iter.cons\]](move.iter.cons.md)

**1** The template parameter `Iterator` shall either meet the *Cpp17InputIterator* requirements ([[input.iterators]](input.iterators.md)) or model `input_iterator` ([[iterator.concept.input]](iterator.concept.input.md)). Additionally, if any of the bidirectional traversal functions are instantiated, the template parameter shall either meet the *Cpp17BidirectionalIterator* requirements ([[bidirectional.iterators]](bidirectional.iterators.md)) or model `bidirectional_iterator` ([[iterator.concept.bidir]](iterator.concept.bidir.md)). If any of the random access traversal functions are instantiated, the template parameter shall either meet the *Cpp17RandomAccessIterator* requirements ([[random.access.iterators]](random.access.iterators.md)) or model `random_access_iterator` ([[iterator.concept.random.access]](iterator.concept.random.access.md)).
