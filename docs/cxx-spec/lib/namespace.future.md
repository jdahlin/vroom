# 16.5.4.2.3 Namespaces for future standardization [namespace.future]

[Contents](../README.md) · up: [16.5.4.2 Namespace use \[namespace.constraints\]](namespace.constraints.md) · prev: [16.5.4.2.2 Namespace `posix` \[namespace.posix\]](namespace.posix.md) · next: [16.5.4.3 Reserved names \[reserved.names\]](reserved.names.md)

**1** Top-level namespaces whose *namespace-name* consists of `std` followed by one or more *digit*s ([[lex.name]](../lex.name.md)) are reserved for future standardization. The behavior of a C++ program is undefined if it adds declarations or definitions to such a namespace. [*Example 1*: The top-level namespace `std2` is reserved for use by future revisions of this International Standard. — *end example*]
