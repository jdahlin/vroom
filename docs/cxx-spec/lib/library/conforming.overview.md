# 16.5.5.1 Overview [conforming.overview]

[Contents](../../README.md) · up: [16.5.5 Conforming implementations \[conforming\]](conforming.md) · prev: [16.5.5 Conforming implementations \[conforming\]](conforming.md) · next: [16.5.5.2 Headers \[res.on.headers\]](res.on.headers.md)

**1** Subclause [[conforming]](conforming.md) describes the constraints upon, and latitude of, implementations of the C++ standard library.

**2** An implementation’s use of headers is discussed in [[res.on.headers]](res.on.headers.md), its use of macros in [[res.on.macro.definitions]](res.on.macro.definitions.md), non-member functions in [[global.functions]](global.functions.md), member functions in [[member.functions]](member.functions.md), data race avoidance in [[res.on.data.races]](res.on.data.races.md), access specifiers in [[protection.within.classes]](protection.within.classes.md), class derivation in [[derivation]](derivation.md), and exceptions in [[res.on.exception.handling]](res.on.exception.handling.md).
