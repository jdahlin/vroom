# 16.5.5.16 Moved-from state of library types [lib.types.movedfrom]

[Contents](../../README.md) · up: [16.5.5 Conforming implementations \[conforming\]](conforming.md) · prev: [16.5.5.15 Value of error codes \[value.error.codes\]](value.error.codes.md) · next: [17 Language support library \[support\]](../support/support.md)

**1** Objects of types defined in the C++ standard library may be moved from ([[class.copy.ctor]](../../class/class.copy.ctor.md)). Move operations may be explicitly specified or implicitly generated. Unless otherwise specified, such moved-from objects shall be placed in a valid but unspecified state.
