# 16.5.4.1 Overview [constraints.overview]

[Contents](../../README.md) · up: [16.5.4 Constraints on programs \[constraints\]](constraints.md) · prev: [16.5.4 Constraints on programs \[constraints\]](constraints.md) · next: [16.5.4.2 Namespace use \[namespace.constraints\]](namespace.constraints.md)

**1** Subclause [[constraints]](constraints.md) describes restrictions on C++ programs that use the facilities of the C++ standard library. The following subclauses specify constraints on the program’s use of namespaces ([[namespace.std]](namespace.std.md)), its use of various reserved names ([[reserved.names]](reserved.names.md)), its use of headers ([[alt.headers]](alt.headers.md)), its use of standard library classes as base classes ([[derived.classes]](derived.classes.md)), its definitions of replacement functions ([[replacement.functions]](replacement.functions.md)), and its installation of handler functions during execution ([[handler.functions]](handler.functions.md)).
