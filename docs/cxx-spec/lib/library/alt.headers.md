# 16.5.4.4 Headers [alt.headers]

**1** If a file with a name equivalent to the derived file name for one of the C++ standard library headers is not provided as part of the implementation, and a file with that name is placed in any of the standard places for a source file to be included ([[cpp.include]](../../cpp/cpp.include.md)), the behavior is undefined.
