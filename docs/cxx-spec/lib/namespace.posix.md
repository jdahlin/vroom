# 16.5.4.2.2 Namespace `posix` [namespace.posix]

[Contents](../README.md) · up: [16.5.4.2 Namespace use \[namespace.constraints\]](namespace.constraints.md) · prev: [16.5.4.2.1 Namespace `std` \[namespace.std\]](namespace.std.md) · next: [16.5.4.2.3 Namespaces for future standardization \[namespace.future\]](namespace.future.md)

**1** The behavior of a C++ program is undefined if it adds declarations or definitions to namespace `posix` or to a namespace within namespace `posix` unless otherwise specified. The namespace `posix` is reserved for use by ISO/IEC 9945 and other POSIX standards.
