# 22.6.6 Class template `stack` [stack]

[Contents](../../README.md) · up: [22.6 Container adaptors \[container.adaptors\]](container.adaptors.md) · prev: [22.6.5.5 Specialized algorithms \[priqueue.special\]](priqueue.special.md) · next: [22.6.6.1 Definition \[stack.defn\]](stack.defn.md)

**1** Any sequence container supporting operations `back()`, `push_back()` and `pop_back()` can be used to instantiate `stack`. In particular, `vector` ([[vector]](vector.md)), `list` ([[list]](list.md)) and `deque` ([[deque]](deque.md)) can be used.
