# 22.5.1 In general [unord.general]

[Contents](../../README.md) · up: [22.5 Unordered associative containers \[unord\]](unord.md) · prev: [22.5 Unordered associative containers \[unord\]](unord.md) · next: [22.5.2 Header `<unordered_map>` synopsis \[unord.map.syn\]](unord.map.syn.md)

**1** The header `<unordered_map>` defines the class templates `unordered_map` and `unordered_multimap`; the header `<unordered_set>` defines the class templates `unordered_set` and `unordered_multiset`.

**2** The exposition-only alias templates `iter-value-type`, `iter-key-type`, `iter-mapped-type`, and `iter-to-alloc-type` defined in [[associative.general]](associative.general.md) may appear in deduction guides for unordered containers.
