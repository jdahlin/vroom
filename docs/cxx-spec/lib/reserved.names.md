# 16.5.4.3 Reserved names [reserved.names]

[Contents](../README.md) · up: [16.5.4 Constraints on programs \[constraints\]](constraints.md) · prev: [16.5.4.2.3 Namespaces for future standardization \[namespace.future\]](namespace.future.md) · next: [16.5.4.3.1 Zombie names \[zombie.names\]](zombie.names.md)

**1** The C++ standard library reserves the following kinds of names:

- macros
- global names
- names with external linkage

**2** If a program declares or defines a name in a context where it is reserved, other than as explicitly allowed by this Clause, its behavior is undefined.
