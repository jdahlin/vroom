# 28.4 Standard `locale` categories [locale.categories]

[Contents](../../README.md) · up: [28 Localization library \[localization\]](localization.md) · prev: [28.3.3.2.1 Character conversions \[conversions.character\]](conversions.character.md) · next: [28.4.1 The `ctype` category \[category.ctype\]](category.ctype.md)

**1** Each of the standard categories includes a family of facets. Some of these implement formatting or parsing of a datum, for use by standard or users’ iostream operators `<<` and `>>`, as members `put()` and `get()`, respectively. Each such member function takes an `ios_base&` argument whose members `flags()`, `precision()`, and `width()`, specify the format of the corresponding datum ([[ios.base]](../io/ios.base.md)). Those functions which need to use other facets call its member `getloc()` to retrieve the locale imbued there. Formatting facets use the character argument `fill` to fill out the specified width where necessary.

**2** The `put()` members make no provision for error reporting. (Any failures of the OutputIterator argument can be extracted from the returned iterator.) The `get()` members take an `ios_base::iostate&` argument whose value they ignore, but set to `ios_base::failbit` in case of a parse error.

**3** Within this clause it is unspecified whether one virtual function calls another virtual function.
