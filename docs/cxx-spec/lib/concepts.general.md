# 18.1 General [concepts.general]

[Contents](../README.md) · up: [18 Concepts library \[concepts\]](concepts.md) · prev: [18 Concepts library \[concepts\]](concepts.md) · next: [18.2 Equality preservation \[concepts.equality\]](concepts.equality.md)

**1** This Clause describes library components that C++ programs may use to perform compile-time validation of template arguments and perform function dispatch based on properties of types. The purpose of these concepts is to establish a foundation for equational reasoning in programs.

**2** The following subclauses describe language-related concepts, comparison concepts, object concepts, and callable concepts as summarized in [Table 39](concepts.general.md#tab:concepts.summary).
