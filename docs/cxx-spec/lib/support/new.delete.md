**1** Except where otherwise specified, the provisions of [[basic.stc.dynamic]](../../basic/basic.stc.dynamic.md) apply to the library versions of `operator new` and `operator delete`. If the value of an alignment argument passed to any of these functions is not a valid alignment value, the behavior is undefined.
