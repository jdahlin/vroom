# 32.9.1 Overview [futures.overview]

[Contents](../README.md) · up: [32.9 Futures \[futures\]](futures.md) · prev: [32.9 Futures \[futures\]](futures.md) · next: [32.9.2 Header `<future>` synopsis \[future.syn\]](future.syn.md)

**1** [[futures]](futures.md) describes components that a C++ program can use to retrieve in one thread the result (value or exception) from a function that has run in the same thread or another thread. [*Note 1*: These components are not restricted to multi-threaded programs but can be useful in single-threaded programs as well. — *end note*]
