# 16.5 Library-wide requirements [requirements]

[Contents](../README.md) · up: [16 Library introduction \[library\]](library.md) · prev: [16.4.2.4 Private members \[objects.within.classes\]](objects.within.classes.md) · next: [16.5.1 Library contents and organization \[organization\]](organization.md)

**1** This subclause specifies requirements that apply to the entire C++ standard library. [[support]](support.md) through [[thread]](thread.md) and [[depr]](../depr.md) specify the requirements of individual entities within the library.

**2** Requirements specified in terms of interactions between threads do not apply to programs having only a single thread of execution.

**3** Within this subclause, [[organization]](organization.md) describes the library’s contents and organization, [[using]](using.md) describes how well-formed C++ programs gain access to library entities, [[utility.requirements]](utility.requirements.md) describes constraints on types and functions used with the C++ standard library, [[constraints]](constraints.md) describes constraints on well-formed C++ programs, and [[conforming]](conforming.md) describes constraints on conforming implementations.
