# C.6.2.1 Types `char16_t` and `char32_t` [diff.char16]

[Contents](README.md) · up: [C.6.2 Modifications to definitions \[diff.mods.to.definitions\]](diff.mods.to.definitions.md) · prev: [C.6.2 Modifications to definitions \[diff.mods.to.definitions\]](diff.mods.to.definitions.md) · next: [C.6.2.2 Type `wchar_t` \[diff.wchar.t\]](diff.wchar.t.md)

**1** The types `char16_t` and `char32_t` are distinct types rather than typedefs to existing integral types. The tokens `char16_t` and `char32_t` are keywords in this International Standard ([[lex.key]](lex.key.md)). They do not appear as macro or type names defined in `<cuchar>` ([[cuchar.syn]](lib/cuchar.syn.md)).
