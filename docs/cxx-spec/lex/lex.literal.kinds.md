# 5.13.1 Kinds of literals [lex.literal.kinds]

[Contents](../README.md) · up: [5.13 Literals \[lex.literal\]](lex.literal.md) · prev: [5.13 Literals \[lex.literal\]](lex.literal.md) · next: [5.13.2 Integer literals \[lex.icon\]](lex.icon.md)

**1** There are several kinds of literals.[^1]

```bnf
literal:
    integer-literal
    character-literal
    floating-point-literal
    string-literal
    boolean-literal
    pointer-literal
    user-defined-literal
```

[^1]: The term “literal” generally designates, in this document, those tokens that are called “constants” in ISO C.
