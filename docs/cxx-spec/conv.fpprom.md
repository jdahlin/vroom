# 7.3.7 Floating-point promotion [conv.fpprom]

[Contents](README.md) · up: [7.3 Standard conversions \[conv\]](conv.md) · prev: [7.3.6 Integral promotions \[conv.prom\]](conv.prom.md) · next: [7.3.8 Integral conversions \[conv.integral\]](conv.integral.md)

**1** A prvalue of type `float` can be converted to a prvalue of type `double`. The value is unchanged.

**2** This conversion is called *floating-point promotion*.
