# C.4.6 [[library]](../lib/library/library.md): library introduction [diff.cpp03.library]

[Contents](../README.md) · up: [C.4 C++ and ISO C++ 2003 \[diff.cpp03\]](diff.cpp03.md) · prev: [C.4.5 [[temp]](../temp/temp.md): templates \[diff.cpp03.temp\]](diff.cpp03.temp.md) · next: [C.4.7 [[support]](../lib/support/support.md): language support library \[diff.cpp03.language.support\]](diff.cpp03.language.support.md)

**1** **Affected:** [[library]](../lib/library/library.md) – [[thread]](../lib/thread/thread.md) <br>**Change:** New reserved identifiers. <br>**Rationale:** Required by new features. <br>**Effect on original feature:** Valid C++ 2003 code that uses any identifiers added to the C++ standard library by this International Standard may fail to compile or produce different results in this International Standard. A comprehensive list of identifiers used by the C++ standard library can be found in the Index of Library Names in this International Standard.

**2** **Affected subclause:** [[headers]](../lib/library/headers.md) <br>**Change:** New headers. <br>**Rationale:** New functionality. <br>**Effect on original feature:** The following C++ headers are new: `<array>` ([[array.syn]](../lib/containers/array.syn.md)), `<atomic>` ([[atomics.syn]](../lib/atomics/atomics.syn.md)), `<chrono>` ([[time.syn]](../lib/time/time.syn.md)), `<codecvt>` ([[depr.codecvt.syn]](../depr/depr.codecvt.syn.md)), `<condition_variable>` ([[condition.variable.syn]](../lib/thread/condition.variable.syn.md)), `<forward_list>` ([[forward.list.syn]](../lib/containers/forward.list.syn.md)), `<future>` ([[future.syn]](../lib/thread/future.syn.md)), `<initializer_list>` ([[initializer.list.syn]](../lib/support/initializer.list.syn.md)), `<mutex>` ([[mutex.syn]](../lib/thread/mutex.syn.md)), `<random>` ([[rand.synopsis]](../lib/numerics/rand.synopsis.md)), `<ratio>` ([[ratio.syn]](../lib/utilities/ratio.syn.md)), `<regex>` ([[re.syn]](../lib/re/re.syn.md)), `<scoped_allocator>` ([[allocator.adaptor.syn]](../lib/utilities/allocator.adaptor.syn.md)), `<system_error>` ([[system.error.syn]](../lib/diagnostics/system.error.syn.md)), `<thread>` ([[thread.syn]](../lib/thread/thread.syn.md)), `<tuple>` ([[tuple.syn]](../lib/utilities/tuple.syn.md)), `<typeindex>` ([[type.index.synopsis]](../lib/utilities/type.index.synopsis.md)), `<type_traits>` ([[meta.type.synop]](../lib/utilities/meta.type.synop.md)), `<unordered_map>` ([[unord.map.syn]](../lib/containers/unord.map.syn.md)), and `<unordered_set>` ([[unord.set.syn]](../lib/containers/unord.set.syn.md)). In addition the following C compatibility headers are new: `<cfenv>` ([[cfenv.syn]](../lib/numerics/cfenv.syn.md)), `<cinttypes>` ([[cinttypes.syn]](../lib/io/cinttypes.syn.md)), `<cstdint>` ([[cstdint.syn]](../lib/support/cstdint.syn.md)), and `<cuchar>` ([[cuchar.syn]](../lib/strings/cuchar.syn.md)). Valid C++ 2003 code that `#include`s headers with these names may be invalid in this International Standard.

**3** **Affected subclause:** [[swappable.requirements]](../lib/library/swappable.requirements.md) <br>**Effect on original feature:** Function `swap` moved to a different header <br>**Rationale:** Remove dependency on `<algorithm>` ([[algorithm.syn]](../lib/algorithms/algorithm.syn.md)) for `swap`. <br>**Effect on original feature:** Valid C++ 2003 code that has been compiled expecting swap to be in `<algorithm>` ([[algorithm.syn]](../lib/algorithms/algorithm.syn.md)) may have to instead include `<utility>` ([[utility.syn]](../lib/utilities/utility.syn.md)).

**4** **Affected subclause:** [[namespace.posix]](../lib/library/namespace.posix.md) <br>**Change:** New reserved namespace. <br>**Rationale:** New functionality. <br>**Effect on original feature:** The global namespace `posix` is now reserved for standardization. Valid C++ 2003 code that uses a top-level namespace `posix` may be invalid in this International Standard.

**5** **Affected subclause:** [[res.on.macro.definitions]](../lib/library/res.on.macro.definitions.md) <br>**Change:** Additional restrictions on macro names. <br>**Rationale:** Avoid hard to diagnose or non-portable constructs. <br>**Effect on original feature:** Names of attribute identifiers may not be used as macro names. Valid C++ 2003 code that defines `override`, `final`, `carries_dependency`, or `noreturn` as macros is invalid in this International Standard.
