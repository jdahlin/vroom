# C.1.9 [[library]](../lib/library/library.md): library introduction [diff.cpp17.library]

[Contents](../README.md) · up: [C.1 C++ and ISO C++ 2017 \[diff.cpp17\]](diff.cpp17.md) · prev: [C.1.8 [[except]](../except/except.md): exception handling \[diff.cpp17.except\]](diff.cpp17.except.md) · next: [C.1.10 [[containers]](../lib/containers/containers.md): containers library \[diff.cpp17.containers\]](diff.cpp17.containers.md)

**1** **Affected subclause:** [[headers]](../lib/library/headers.md) <br>**Change:** New headers. <br>**Rationale:** New functionality. <br>**Effect on original feature:** The following C++ headers are new: `<barrier>` ([[barrier.syn]](../lib/thread/barrier.syn.md)), `<bit>` ([[bit.syn]](../lib/numerics/bit.syn.md)), `<charconv>` ([[charconv.syn]](../lib/utilities/charconv.syn.md)), `<compare>` ([[compare.syn]](../lib/support/compare.syn.md)), `<concepts>` ([[concepts.syn]](../lib/concepts/concepts.syn.md)), `<coroutine>` ([[coroutine.syn]](../lib/support/coroutine.syn.md)), `<format>` ([[format.syn]](../lib/utilities/format.syn.md)), `<latch>` ([[latch.syn]](../lib/thread/latch.syn.md)), `<numbers>` ([[numbers.syn]](../lib/numerics/numbers.syn.md)), `<ranges>` ([[ranges.syn]](../lib/ranges/ranges.syn.md)), `<semaphore>` ([[semaphore.syn]](../lib/thread/semaphore.syn.md)), `<source_location>` ([[source.location.syn]](../lib/support/source.location.syn.md)), `<span>` ([[span.syn]](../lib/containers/span.syn.md)), `<stop_token>` ([[thread.stoptoken.syn]](../lib/thread/thread.stoptoken.syn.md)), `<syncstream>` ([[syncstream.syn]](../lib/io/syncstream.syn.md)), and `<version>` ([[support.limits.general]](../lib/support/support.limits.general.md)). Valid C++ 2017 code that `#include`s headers with these names may be invalid in this International Standard.

**2** **Affected subclause:** [[headers]](../lib/library/headers.md) <br>**Change:** Remove vacuous C++ header files. <br>**Rationale:** The empty headers implied a false requirement to achieve C compatibility with the C++ headers. <br>**Effect on original feature:** A valid C++ 2017 program that `#include`s any of the following headers may fail to compile: `<ccomplex>`, `<ciso646>`, `<cstdalign>`, `<cstdbool>`, and `<ctgmath>`. To retain the same behavior:

- a `#include` of `<ccomplex>` can be replaced by a `#include` of `<complex>` ([[complex.syn]](../lib/numerics/complex.syn.md)),
- a `#include` of `<ctgmath>` can be replaced by a `#include` of `<cmath>` ([[cmath.syn]](../lib/numerics/cmath.syn.md)) and a `#include` of `<complex>`, and
- a `#include` of `<ciso646>`, `<cstdalign>`, or `<cstdbool>` can simply be removed.
