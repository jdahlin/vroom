# C.6.4 Modifications to behavior [diff.mods.to.behavior]

[Contents](../README.md) · up: [C.6 C standard library \[diff.library\]](diff.library.md) · prev: [C.6.3 Modifications to declarations \[diff.mods.to.declarations\]](diff.mods.to.declarations.md) · next: [C.6.4.1 Macro `offsetof(type, member-designator)` \[diff.offsetof\]](diff.offsetof.md)

**1** Header `<cstdlib>` ([[cstdlib.syn]](../lib/support/cstdlib.syn.md)): The following functions have different behavior:

- `atexit`
- `exit`
- `abort`

Subclause [[support.start.term]](../lib/support/support.start.term.md) describes the changes.

**2** Header `<csetjmp>` ([[csetjmp.syn]](../lib/support/csetjmp.syn.md)): The following functions have different behavior:

- `longjmp`

Subclause [[csetjmp.syn]](../lib/support/csetjmp.syn.md) describes the changes.
