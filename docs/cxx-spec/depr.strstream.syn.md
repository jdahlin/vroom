# D.12.1 Header `<strstream>` synopsis [depr.strstream.syn]

[Contents](README.md) · up: [D.12 `char*` streams \[depr.str.strstreams\]](depr.str.strstreams.md) · prev: [D.12 `char*` streams \[depr.str.strstreams\]](depr.str.strstreams.md) · next: [D.12.2 Class `strstreambuf` \[depr.strstreambuf\]](depr.strstreambuf.md)

**1** The header `<strstream>` defines types that associate stream buffers with character array objects and assist reading and writing such objects.

```cpp
namespace std {
  class strstreambuf;
  class istrstream;
  class ostrstream;
  class strstream;
}
```
