# C.2.7 [[library]](lib/library.md): library introduction [diff.cpp14.library]

[Contents](README.md) · up: [C.2 C++ and ISO C++ 2014 \[diff.cpp14\]](diff.cpp14.md) · prev: [C.2.6 [[except]](except.md): exception handling \[diff.cpp14.except\]](diff.cpp14.except.md) · next: [C.2.8 [[utilities]](lib/utilities.md): general utilities library \[diff.cpp14.utilities\]](diff.cpp14.utilities.md)

**1** **Affected subclause:** [[headers]](lib/headers.md) <br>**Change:** New headers. <br>**Rationale:** New functionality. <br>**Effect on original feature:** The following C++ headers are new: `<any>` ([[any.synop]](lib/any.synop.md)), `<charconv>` ([[charconv.syn]](lib/charconv.syn.md)), `<execution>` ([[execution.syn]](lib/execution.syn.md)), `<filesystem>` ([[fs.filesystem.syn]](lib/fs.filesystem.syn.md)), `<memory_resource>` ([[mem.res.syn]](lib/mem.res.syn.md)), `<optional>` ([[optional.syn]](lib/optional.syn.md)),<br> `<string_view>` ([[string.view.synop]](lib/string.view.synop.md)), and `<variant>` ([[variant.syn]](lib/variant.syn.md)). Valid C++ 2014 code that `#include`s headers with these names may be invalid in this International Standard.

**2** **Affected subclause:** [[namespace.future]](lib/namespace.future.md) <br>**Change:** New reserved namespaces. <br>**Rationale:** Reserve namespaces for future revisions of the standard library that might otherwise be incompatible with existing programs. <br>**Effect on original feature:** The global namespaces `std` followed by an arbitrary sequence of *digit*s ([[lex.name]](lex.name.md)) are reserved for future standardization. Valid C++ 2014 code that uses such a top-level namespace, e.g., `std2`, may be invalid in this International Standard.
