# D.9.1 Header `<complex.h>` synopsis [depr.complex.h.syn]

[Contents](../README.md) · up: [D.9 C headers \[depr.c.headers\]](depr.c.headers.md) · prev: [D.9 C headers \[depr.c.headers\]](depr.c.headers.md) · next: [D.9.2 Header `<iso646.h>` synopsis \[depr.iso646.h.syn\]](depr.iso646.h.syn.md)

```cpp
#include <complex>
```

**1** The header `<complex.h>` behaves as if it simply includes the header `<complex>` ([[complex.syn]](../lib/numerics/complex.syn.md)).

**2** [*Note 1*: Names introduced by `<complex>` in namespace `std` are not placed into the global namespace scope by `<complex.h>`. — *end note*]
