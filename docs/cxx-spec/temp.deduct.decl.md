# 13.10.2.6 Deducing template arguments from a function declaration [temp.deduct.decl]

[Contents](README.md) · up: [13.10.2 Template argument deduction \[temp.deduct\]](temp.deduct.md) · prev: [13.10.2.5 Deducing template arguments from a type \[temp.deduct.type\]](temp.deduct.type.md) · next: [13.10.3 Overload resolution \[temp.over\]](temp.over.md)

**1** In a declaration whose *declarator-id* refers to a specialization of a function template, template argument deduction is performed to identify the specialization to which the declaration refers. Specifically, this is done for explicit instantiations ([[temp.explicit]](temp.explicit.md)), explicit specializations ([[temp.expl.spec]](temp.expl.spec.md)), and certain friend declarations ([[temp.friend]](temp.friend.md)). This is also done to determine whether a deallocation function template specialization matches a placement `operator new` ([[basic.stc.dynamic.deallocation]](basic.stc.dynamic.deallocation.md), [[expr.new]](expr.new.md)). In all these cases, `P` is the type of the function template being considered as a potential match and `A` is either the function type from the declaration or the type of the deallocation function that would match the placement `operator new` as described in [[expr.new]](expr.new.md). The deduction is done as described in [[temp.deduct.type]](temp.deduct.type.md).

**2** If, for the set of function templates so considered, there is either no match or more than one match after partial ordering has been considered ([[temp.func.order]](temp.func.order.md)), deduction fails and, in the declaration cases, the program is ill-formed.
