# C++ standard working draft n4861, split by subclause

Generated by `bench/cxx-spec.py --tag n4861` from the LaTeX sources of
<https://github.com/cplusplus/draft>; do not edit by hand, rerun the script.
n4861 is the final working draft of C++20 (ISO/IEC 14882:2020).

- One directory per clause, one file per subclause named by its stable name:
  `[expr.add]` is [expr/expr.add.md](expr/expr.add.md).  The directory is the
  clause the subclause belongs to, which is usually but not always the first
  part of the name (`[conv.lval]` is in `expr/`, `[namespace.def]` in `dcl/`):
  `ls */NAME.md lib/*/NAME.md` finds any of them.  The library clauses
  (`[library]` to `[thread]`) are under [lib/](lib/README.md), also one
  directory per clause: `[vector]` is `lib/containers/vector.md`.
- A file holds the subclause's own paragraphs (**1**, **2**, ... as numbered in
  the standard, so `[expr.add]/4` is paragraph **4** of `expr.add.md`), then
  the list of its subclauses.  The first line links to the parent and to the
  previous and next subclause in document order.
- Cross references are links: `[basic.lookup]`.  Tables and figures keep their
  numbers and have anchors `#tab:NAME`, `#fig:NAME`; the terms of
  [intro.defs](intro/intro.defs.md) have an anchor each.
- Grammar is in `bnf` blocks: terminals are quoted (`'class'`), nonterminals
  are bare, `ₒₚₜ` marks an optional symbol.  In running text nonterminals are
  *italic*.  [grammar-index.md](grammar-index.md) lists every nonterminal with
  the subclause that defines it; [gram](gram/gram.md) is the standard's own summary.
- Notes and examples are numbered within their subclause and bracketed:
  [*Note 1*: ... — *end note*].  Footnotes are at the end of the file.
- 2468 subclauses, 573 of them outside the library.
