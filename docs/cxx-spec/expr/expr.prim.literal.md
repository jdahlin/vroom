# 7.5.1 Literals [expr.prim.literal]

[Contents](../README.md) · up: [7.5 Primary expressions \[expr.prim\]](expr.prim.md) · prev: [7.5 Primary expressions \[expr.prim\]](expr.prim.md) · next: [7.5.2 This \[expr.prim.this\]](expr.prim.this.md)

**1** A *literal* is a primary expression. The type of a *literal* is determined based on its form as specified in [[lex.literal]](../lex/lex.literal.md). A *string-literal* is an lvalue, a *user-defined-literal* has the same value category as the corresponding operator call expression described in [[lex.ext]](../lex/lex.ext.md), and any other *literal* is a prvalue.
