# 6.4.8 Enumeration scope [basic.scope.enum]

[Contents](../README.md) · up: [6.4 Scope \[basic.scope\]](basic.scope.md) · prev: [6.4.7 Class scope \[basic.scope.class\]](basic.scope.class.md) · next: [6.4.9 Template parameter scope \[basic.scope.temp\]](basic.scope.temp.md)

**1** The name of a scoped enumerator ([[dcl.enum]](../dcl/dcl.enum.md)) has *enumeration scope*. Its potential scope begins at its point of declaration and terminates at the end of the *enum-specifier*.
